# Бот РЫБОТЯГ для MAX

Отвечает на вопросы о товаре с ribotyag.ru готовыми ответами по темам
(цена, характеристики, материал, покупка/доставка, отзывы, инструкция, контакты).
Без ИИ и внешних сервисов — только Python 3 (стандартная библиотека, ничего ставить не нужно).

## 1. Получить токен бота

1. В MAX найдите `@MasterBot` и откройте с ним чат.
2. Отправьте `/create`, задайте ник и имя бота (до 16 символов).
3. MasterBot пришлёт токен — сохраните его, это полный доступ к боту.
   Команды `@MasterBot`: `/get_token` — показать токен снова,
   `/refresh_token` — перевыпустить, `/revoke` — отозвать.

## 2. Запуск

Нужен Python 3 (проверить: `python3 --version`).

```bash
MAX_BOT_TOKEN=вставьте_токен python3 bot.py
```

Бот подключится и будет отвечать на сообщения, пока скрипт запущен.
Остановить — Ctrl+C.

## 3. Чтобы бот работал постоянно

Скрипт должен работать без остановки на каком-то компьютере/сервере с интернетом.
Проще всего — недорогой VPS (от ~150₽/мес) и запуск в фоне:

```bash
nohup env MAX_BOT_TOKEN=вставьте_токен python3 bot.py > bot.log 2>&1 &
```

Или через systemd/`screen`/`tmux`, если удобнее.

## 4. Как менять ответы

Все темы и ответы — в `faq.py`, в списке `TOPICS`. Каждая строка — это
набор ключевых слов и текст ответа. Чтобы добавить тему, скопируйте
строку и поменяйте слова/текст. Проверить, что ничего не сломалось:

```bash
python3 test_faq.py
```

## Ограничение текущей версии

Бот получает сообщения через long polling (`GET /updates`) — это самый
простой вариант без сервера, но MAX не рекомендует его для высокой нагрузки
(есть лимиты и события хранятся недолго). Если поток вопросов вырастет,
следующий шаг — перейти на webhook (нужен сервер с HTTPS и доменом).
